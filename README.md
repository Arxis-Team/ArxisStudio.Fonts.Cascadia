# ArxisStudio.Fonts.Cascadia

Моноширинный шрифт **Cascadia Code**, вшитый в сборку и подключаемый одной
строкой. Устроен как `Avalonia.Fonts.Inter`: коллекция `fonts:Cascadia` поверх
встроенных ресурсов.

В ArxisStudio им набраны код, пути и значения — всё, чему тема (ключ
`AxFontFamilyMono`) отдаёт моноширинное начертание.

## Подключение

```csharp
AppBuilder.Configure<App>()
    .UsePlatformDetect()
    .WithCascadiaFont();
```

После этого шрифт доступен в разметке под своим именем:

```xml
<TextBlock FontFamily="fonts:Cascadia#Cascadia Code" Text="&lt;Button/&gt;"/>
```

Вызов обязателен. Без него разметка шрифта не найдёт и молча возьмёт
системный — ошибки не будет, будет другой текст.

## Зачем отдельный репозиторий

Шрифт ехал ресурсом внутри темы `ArxisStudio.Themes.Arxis`, и получалось, что
тема отвечает сразу за две вещи: за вид контролов и за поставку шрифта. Их
жизненные циклы разные — шрифт обновляется от силы раз в год, тема правится
каждый день, — а нужен он не только теме: редактору кода и панели вывода тоже.
